# Security policy

`mmxisf` is not yet released and does not yet parse XISF files. Please do not
use the `0.0.x` scaffold with untrusted input.

Parser implementation will treat every file, XML document, block descriptor,
compressed stream, and external reference as untrusted. Security reports should
be submitted privately through the security-reporting channel configured before
the first public beta. Do not include sensitive or proprietary astronomy data
in a report without explicit permission.
